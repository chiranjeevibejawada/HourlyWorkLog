HOURLY WORK LOG - setup
1. Install Android Studio (free). File > Open > select this HourlyWorkLog folder. Let Gradle sync finish.
2. Connect your Android phone (USB debugging on) and press Run, or Build > Build APK(s) and copy app-debug.apk to the phone.
3. Open the app, allow Microphone + Notifications. In Settings tab: Allow exact alarms, Turn off battery optimization.
4. Alarms fire at 10 AM...6 PM Mon-Fri (for the hour just ended). Excel report is made after the 6 PM entry in Documents/WorkLog.
